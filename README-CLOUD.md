# JARVIS — облачная сборка
Проект настроен для GitHub Actions. Termux и AndroidIDE для сборки не нужны.

1. Создай репозиторий на GitHub.
2. Загрузи содержимое ZIP.
3. Открой Actions → Build JARVIS APK.
4. Нажми Run workflow.
5. После завершения открой Artifacts → JARVIS-debug.
6. Скачай архив и достань app-debug.apk.
